<p align="center"><strong>Figma component replacer</strong></p>
<p align="center">A minimal Figma plugin for finding instances of external or missing components and replacing them in bulk with local components from the same file.</p>

## Features

- Vite
- Vue 3

## Requirements

- Node 18.17.0
- npm

## Setup

Install project dependencies by running the following command:

```bash
npm install
```

## Build

```bash
npm run build
```
