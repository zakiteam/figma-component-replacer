# App Toolbar Styles

This folder contains styles for the app toolbar component.

Styles should stay scoped by convention under the `c-app-toolbar` BEM block:

- `c-app-toolbar`
- `c-app-toolbar__title`
- `c-app-toolbar__actions`
- `c-app-toolbar__button`

Prefer CSS variables from `src/ui/styles/base.css` for spacing, color, radius, and sizing.
