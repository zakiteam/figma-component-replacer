# Orphan List Styles

This folder contains styles for the orphan list component.

Styles should stay scoped by convention under the `c-orphan-list` BEM block:

- `c-orphan-list`
- `c-orphan-list__item`
- `c-orphan-list__item--active`
- `c-orphan-list__status`
- `c-orphan-list__status--remote`

Prefer CSS variables from `src/ui/styles/base.css` instead of hardcoded design values.
