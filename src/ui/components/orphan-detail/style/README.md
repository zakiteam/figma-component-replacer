# Orphan Detail Styles

This folder contains styles for the orphan detail component.

Styles should stay scoped by convention under the `c-orphan-detail` BEM block:

- `c-orphan-detail`
- `c-orphan-detail__panel`
- `c-orphan-detail__grid`
- `c-orphan-detail__button`
- `c-orphan-detail__button--primary`
- `c-orphan-detail__button--secondary`

Prefer CSS variables from `src/ui/styles/base.css` for all reusable visual decisions.
